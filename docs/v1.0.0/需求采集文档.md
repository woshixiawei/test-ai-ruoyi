 # 需求采集文档
- 版本号: v1.0.0
- 作者: 需求采集专员
- 日期: 2026-05-04

## 1. 项目背景

开发一款类似于若依（RuoYi）的通用后台管理系统，作为公司内部统一的后台系统基础模板。该模板将作为标准化开发框架，供公司内部开发团队在构建新业务系统时直接使用，以避免重复开发基础功能模块，提高开发效率和代码一致性。

## 2. 用户角色

| 角色 | 描述 | 权限范围 |
|------|------|---------|
| 系统管理员 | 负责系统初始化配置、用户/角色/菜单管理 | 全部权限 |
| 运营管理人员 | 负责系统配置、数据管理和业务操作 | 按分配角色权限 |
| 普通用户 | 系统日常使用者 | 按分配角色权限 |

## 3. 功能需求

### 3.1 用户管理
- 需求描述: 系统用户是系统操作者，完成系统用户配置管理
- 用户故事: 作为系统管理员，我希望管理系统的用户信息，以便控制谁能访问系统和拥有什么权限
- 验收标准:
  - [ ] 支持用户增删改查操作
  - [ ] 支持用户状态管理（启用/禁用）
  - [ ] 支持密码重置功能
  - [ ] 支持为用户分配角色
  - [ ] 支持为用户分配部门
  - [ ] 支持列表分页查询和条件筛选
  - [ ] 支持按钮级权限控制（新增、编辑、删除、重置密码按钮按角色显示/隐藏）

### 3.2 角色管理
- 需求描述: 角色是权限集合，负责角色菜单权限分配
- 用户故事: 作为系统管理员，我希望创建角色并分配权限，以便不同用户拥有不同的系统访问能力
- 验收标准:
  - [ ] 支持角色增删改查操作
  - [ ] 支持为角色分配菜单权限
  - [ ] 支持为角色分配按钮权限（通过权限标识控制）
  - [ ] 支持列表分页查询
  - [ ] 支持按钮级权限控制

### 3.3 菜单管理
- 需求描述: 配置系统菜单和按钮权限标识
- 用户故事: 作为系统管理员，我希望配置系统的菜单结构和按钮权限，以便控制用户能看到哪些页面和操作
- 验收标准:
  - [ ] 支持菜单/按钮增删改查操作
  - [ ] 支持树形结构展示和管理
  - [ ] 支持配置权限标识（用于按钮级权限控制）
  - [ ] 支持配置菜单图标

  - [ ] 支持按钮级权限控制

  - [ ] 支持部门增删改查操作

### 3.5 岗位管理

## 4. 非功能需求

### 4.1 性能要求
- 系统需支持同时在线用户数 1000 人
- 常规页面响应时间 <= 500ms
- 列表查询响应时间 <= 1s
- 数据库连接池、缓存策略按此规模配置

### 4.2 安全要求
- 身份认证：基于 sa-token 的认证机制
- 权限控制：RBAC 模型，支持菜单级和按钮级权限控制
- SQL 注入防护：使用 MyBatis-Plus 参数化查询
- 密码加密存储
- 接口访问权限校验

### 4.3 可用性要求
- 提供友好的管理界面和清晰的操作流程
- 表单输入校验和友好的错误提示
- 操作确认和防误触机制

### 4.4 可扩展性要求
- 代码结构清晰，模块化设计，便于后续功能扩展
- 配置化设计，减少硬编码
- 预留扩展接口，便于定制开发

### 4.5 维护性要求
- 代码注释清晰，命名规范
- 统一的异常处理机制
- 完善的日志记录

## 5. 业务规则

1. **用户状态规则**：用户状态分为启用和禁用，禁用用户无法登录系统
2. **角色分配规则**：一个用户可以拥有多个角色，用户权限为所有角色权限的并集
3. **菜单权限规则**：菜单分为目录、菜单、按钮三种类型；目录和菜单控制页面访问，按钮控制操作权限
4. **部门规则**：部门支持树形结构，支持无限层级
5. **超级管理员规则**：超级管理员拥有全部权限，不可被删除和禁用
6. **密码规则**：密码长度 6-20 位，支持数字、字母、特殊字符组合
7. **文件上传规则**：单文件大小不超过 50MB，支持图片、文档、压缩包等常见格式
8. **日志保留规则**：操作日志和登录日志默认保留 30 天，超期可自动清理

## 6. 数据范围

- 用户数量：初期支持 1 万以内用户
- 部门层级：支持无限层级树形结构
- 角色数量：无硬性上限，建议 100 个以内
- 菜单数量：无硬性上限，建议 200 个以内
- 日志数据：日增量约 1-10 万条，支持定期清理
- 文件存储：初期支持本地存储，预留对象存储扩展接口

## 7. 术语表

| 术语 | 解释 |
|------|------|
| RBAC | Role-Based Access Control，基于角色的访问控制 |
| sa-token | 一个轻量级 Java 权限认证框架，支持登录认证、权限认证、分布式会话、单点登录等 |
| JWT | JSON Web Token，可用于 sa-token 的 Token 风格配置 |
| Shiro | Apache Shiro，Java 安全框架（本项目中不采用）|
| MyBatis-Plus | MyBatis 的增强工具，简化 CRUD 操作 |
| V3 Admin Vite | 基于 Vue3 + Vite 的后台管理前端模板 |
| CRUD | Create（创建）、Read（读取）、Update（更新）、Delete（删除） |
| MVP | Minimum Viable Product，最小可行产品 |
| 数据权限 | 控制用户能看到的数据范围（本版本不实现） |
| 按钮级权限 | 通过权限标识控制页面上按钮的显示/隐藏 |
