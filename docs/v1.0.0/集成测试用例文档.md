# 集成测试用例文档

- 版本号: v1.0.0
- 关联文档: docs/v1.0.0/PRD文档.md、docs/v1.0.0/API接口设计.md、docs/v1.0.0/单元测试报告.md
- 测试类型: 端到端集成测试（前后端联调 + sa-token 认证框架集成验证）
- 后端地址: http://localhost:8080
- 前端地址: http://localhost:3333
- 测试账号: admin/admin123（超级管理员）、zhangsan/123456（普通角色）
- 数据库: MySQL 8.0 (192.168.29.132:3306/test_ruoyi)
- 认证方式: sa-token（Header: Authorization）

---

## 1. 测试目标

验证前后端联调场景下的完整用户操作流程，重点覆盖单元测试无法验证的 sa-token 认证授权机制、跨模块交互、端到端数据流转。

## 3. 集成测试用例

### 3.1 认证授权模块（IT-AUTH）

#### IT-AUTH-001 管理员登录成功
- **前置条件**: 数据库已有 admin 用户（status=1）
- **测试步骤**:
  1. POST /backend/auth/login，Body: `{"username":"admin","password":"admin123"}`
- **预期结果**:
  - HTTP 200
  - code=0, success=true
  - data.token 为非空 UUID 字符串
  - data.userInfo.username="admin"

#### IT-AUTH-002 普通用户登录成功
- **前置条件**: 数据库已有 zhangsan 用户（status=1）
- **测试步骤**:
  1. POST /backend/auth/login，Body: `{"username":"zhangsan","password":"123456"}`
- **预期结果**:
  - HTTP 200
  - code=0, success=true
  - data.token 为非空 UUID 字符串

#### IT-AUTH-003 错误密码登录失败
- **前置条件**: 数据库已有 admin 用户
- **测试步骤**:
  1. POST /backend/auth/login，Body: `{"username":"admin","password":"wrongpassword"}`
- **预期结果**:
  - HTTP 200
  - code=50002, success=false
  - msg 包含"用户名或密码错误"

#### IT-AUTH-004 停用账号登录失败
- **前置条件**: 存在 status=0 的用户
- **测试步骤**:
  1. 先用 admin 登录获取 token
  2. PUT /backend/system/user/2/status，Body: `{"status":0}`
  3. POST /backend/auth/login，Body: `{"username":"zhangsan","password":"123456"}`
- **预期结果**:
  - 步骤3: code=50002, success=false
  - msg 包含"账号已停用"
- **清理**: 恢复 zhangsan 状态为1

#### IT-AUTH-005 未登录访问受保护接口
- **测试步骤**:
  1. GET /backend/system/user/list（不携带 Authorization Header）
- **预期结果**:
  - HTTP 200
  - code=50005, success=false
  - msg 包含"未登录"或"Not Login"

#### IT-AUTH-006 获取当前用户信息
- **前置条件**: admin 已登录
- **测试步骤**:
  1. GET /backend/auth/info，Header: Authorization={admin_token}
- **预期结果**:
  - code=0, success=true
  - data.username="admin"
  - data.roles 非空数组，包含"admin"
  - data.permissions 非空数组

#### IT-AUTH-007 获取当前用户路由/菜单
- **前置条件**: admin 已登录
- **测试步骤**:
  1. GET /backend/auth/routes，Header: Authorization={admin_token}
- **预期结果**:
  - code=0, success=true
  - data 为数组，至少包含"系统管理"目录
  - 系统管理下有"用户管理"、"角色管理"等子菜单

#### IT-AUTH-008 获取当前用户权限标识
- **前置条件**: admin 已登录
- **测试步骤**:
  1. GET /backend/auth/permissions，Header: Authorization={admin_token}
- **预期结果**:
  - code=0, success=true
  - data 为数组，包含"system:user:list"、"system:role:list"等

#### IT-AUTH-009 登出后 Token 失效
- **前置条件**: admin 已登录
- **测试步骤**:
  1. POST /backend/auth/logout，Header: Authorization={admin_token}
  2. GET /backend/auth/info，Header: Authorization={admin_token}
- **预期结果**:
  - 步骤1: code=0, success=true
  - 步骤2: code=50005, success=false（Token 已失效）

#### IT-AUTH-010 普通用户权限隔离
- **前置条件**: zhangsan 已登录（common 角色，仅有部分菜单权限）
- **测试步骤**:
  1. GET /backend/auth/routes，Header: Authorization={zhangsan_token}
  2. GET /backend/auth/permissions，Header: Authorization={zhangsan_token}
- **预期结果**:
  - 步骤1: 返回的菜单列表少于 admin
  - 步骤2: 返回的权限标识不包含"system:menu:add"等按钮权限
