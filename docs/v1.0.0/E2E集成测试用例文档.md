# E2E集成测试用例文档（浏览器交互版）

- 版本号: v1.0.0
- 关联文档: docs/v1.0.0/PRD文档.md、docs/v1.0.0/集成测试用例文档.md
- 测试类型: 端到端浏览器集成测试（Playwright MCP 驱动）
- 前端地址: http://localhost:3333
- 后端地址: http://localhost:8080
- 测试账号: admin/admin123（超级管理员）、zhangsan/123456（普通角色）
- 浏览器: Chromium（Playwright MCP）

---

## 1. 测试目标

通过 Playwright MCP 在真实浏览器中执行端到端测试，验证：
- 前端页面渲染是否正确
- 用户交互流程是否通畅
- 前后端联调数据流转是否正确
- 权限控制是否在 UI 层面生效
- 表单提交与数据展示是否一致

## 2. 测试用例

### 2.1 登录页面（E2E-LOGIN）

#### E2E-LOGIN-001 登录页面渲染验证
- **测试步骤**: 打开 http://localhost:3333
- **预期结果**: 
  - 页面正常加载，显示登录表单
  - 包含用户名输入框、密码输入框、登录按钮
  - 无 JS 报错

#### E2E-LOGIN-002 管理员登录成功
- **测试步骤**: 输入 admin/admin123，点击登录
- **预期结果**:
  - 跳转到系统首页（Dashboard）
  - 顶部导航栏显示用户名
  - 左侧菜单正常渲染

#### E2E-LOGIN-003 错误密码登录失败
- **测试步骤**: 输入 admin/wrongpassword，点击登录
- **预期结果**:
  - 停留在登录页
  - 显示错误提示信息

#### E2E-LOGIN-004 普通用户登录
- **测试步骤**: 输入 zhangsan/123456，点击登录
- **预期结果**:
  - 登录成功，进入首页
  - 菜单数量少于 admin

#### E2E-LOGIN-005 登出流程
- **测试步骤**: 登录后点击用户头像下拉菜单，点击退出登录
- **预期结果**:
  - 跳转回登录页面
  - 再次访问系统页面需重新登录
