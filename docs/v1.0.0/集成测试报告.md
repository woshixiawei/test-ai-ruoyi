## 7. 风险与建议

### 7.1 已知限制
1. **前端页面测试**：本次集成测试主要通过 API 接口验证后端功能，前端页面交互测试需人工在浏览器中完成
2. **并发测试**：未进行高并发场景下的性能和安全性测试
3. **文件上传/下载**：文件管理的二进制传输功能需人工验证文件完整性

### 7.2 优化建议
1. 建议后续增加接口自动化测试脚本（如 Postman Collection / Newman），支持 CI/CD 自动回归
2. sa-token 的 activity-timeout 配置项已过期，建议更新为 active-timeout
3. MyBatis-Plus 的 PO 类（UserRolePO、RoleMenuPO）缺少 @TableId 注解的警告，建议后续补充
