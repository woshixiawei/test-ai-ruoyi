## 1. 测试范围

本文档覆盖通用后台管理系统 v1.0.0 全部 12 个核心模块的单元测试用例，聚焦后端 **DomainService** 和 **AppService** 层的业务逻辑测试，覆盖正常流程、异常流程、边界值和权限控制场景。

测试模块清单：

- 认证授权（登录/登出/信息/权限）
- 用户管理
- 角色管理
- 菜单管理
- 部门管理
- 岗位管理
- 字典管理
- 参数配置
- 通知公告
- 操作日志
- 登录日志
- 文件管理
- 个人中心
- RBAC 权限校验

## 2. 测试用例

### 2.1 认证授权模块

#### TC-AUTH-001: 用户登录成功

- 前置条件: 用户存在且状态正常，密码已 BCrypt 加密存储
- 测试步骤:
    1. 调用 AuthDomainService.authenticate(username, password)
    2. 验证用户查询结果
    3. 验证 BCrypt 密码匹配
    4. 验证用户状态为正常
    5. 调用 StpUtil.login(userId)
- 测试数据:
  | 输入 | 期望输出 |
  |------|---------|
  | username="admin", password="正确密码" | Token 字符串，非空 |
- 预期结果: 登录成功，返回有效 Token，记录登录日志
- 优先级: P0
- 类型: 正常流程

#### TC-AUTH-002: 用户登录失败-密码错误

- 前置条件: 用户存在且状态正常
- 测试步骤:
    1. 调用 authenticate(username, 错误密码)
    2. 验证密码不匹配
- 测试数据:
  | 输入 | 期望输出 |
  |------|---------|
  | username="admin", password="wrong" | 抛出异常：用户名或密码错误 |
- 预期结果: 返回 401 错误，记录登录失败日志，登录失败计数 +1
- 优先级: P0
- 类型: 异常流程

#### TC-AUTH-003: 用户登录失败-账号已禁用

- 前置条件: 用户存在但 status = 0（禁用）
- 测试步骤:
    1. 调用 authenticate(username, 正确密码)
    2. 密码校验通过
    3. 检查用户状态
- 预期结果: 抛出异常：账号已停用，返回 403 错误
- 优先级: P0
- 类型: 异常流程

#### TC-AUTH-004: 用户登录失败-账号不存在

- 前置条件: 用户名未注册
- 测试步骤:
    1. 调用 authenticate("不存在的用户", password)
- 预期结果: 抛出异常：用户名或密码错误（不暴露账号不存在）
- 优先级: P0
- 类型: 异常流程

#### TC-AUTH-005: 连续登录失败锁定账号

- 前置条件: 用户存在且状态正常
- 测试步骤:
    1. 连续 5 次使用错误密码登录
    2. 第 6 次使用正确密码登录
- 预期结果: 第 6 次登录被锁定，返回账号已锁定提示
- 优先级: P0
- 类型: 异常流程

#### TC-AUTH-006: 用户登出成功

- 前置条件: 用户已登录，持有有效 Token
- 测试步骤:
    1. 调用 StpUtil.logout()
- 预期结果: 会话注销成功，Token 失效
- 优先级: P0
- 类型: 正常流程

#### TC-AUTH-007: 获取当前用户信息

- 前置条件: 用户已登录
- 测试步骤:
    1. 调用获取用户信息接口
    2. 查询用户基础信息 + 角色列表 + 权限标识列表
- 预期结果: 返回用户信息（不含密码字段）、角色数组、权限数组
- 优先级: P0
- 类型: 正常流程

#### TC-AUTH-008: 获取用户路由菜单

- 前置条件: 用户已登录，已分配角色和菜单
- 测试步骤:
    1. 查询用户角色
    2. 查询角色对应的菜单列表
    3. 构建菜单树结构
- 预期结果: 返回树形菜单结构，仅包含 type=0(目录) 和 type=1(菜单) 的数据
- 优先级: P0
- 类型: 正常流程

#### TC-AUTH-009: 获取用户权限标识

- 前置条件: 用户已登录，已分配角色和按钮权限
- 测试步骤:
    1. 查询用户角色
    2. 查询角色对应的权限标识列表
- 预期结果: 返回权限标识字符串数组，如 `["system:user:list", "system:user:add"]`
- 优先级: P0
- 类型: 正常流程

## 5. 术语表

| 术语     | 解释                                |
|--------|-----------------------------------|
| BCrypt | 自适应密码哈希算法，用于密码加密存储                |
| P0/P1  | 测试用例优先级，P0 为最高优先级（核心流程），P1 为一般优先级 |
| 正常流程   | 符合业务预期的标准操作流程                     |
| 异常流程   | 违反业务规则或系统约束的错误处理流程                |
| 边界值    | 输入数据处于允许范围的边界或极限值的测试场景            |
| 幂等性    | 同一操作多次执行结果与一次执行结果一致               |
| 事务回滚   | 数据库操作失败时，已执行的操作自动撤销，保证数据一致性       |
