# 前端技术栈强制要求

- 版本号: v1.1
- 适用范围: 所有前端项目
- 约束力: **强制**

---

**本章节规定为强制性要求，所有前端项目必须严格遵守，不得有任何例外。**

### 0.1 前端框架（强制）
- **必须使用 Vue 3 作为唯一前端框架**
- **严禁使用 Vue 2、React、Angular 或任何其他前端框架**
- 所有组件、页面、路由、状态管理必须基于 Vue 3 生态构建
- 使用 `<script setup>` 语法 + Composition API 进行组件开发
- 使用 Vue Router 4 进行路由管理
- 使用 Pinia 进行状态管理

### 0.2 编程语言（强制）
- **必须使用 TypeScript 进行全部开发**
- **严禁使用 JavaScript（`.js` 文件一律禁止）**
- 所有源文件后缀必须为 `.ts`、`.tsx` 或 `.vue`（且必须包含 `lang="ts"`）
- `.js` 文件仅在第三方库或构建配置文件（如 `vite.config.js`）中允许存在

### 0.3 开源优先原则（强制）
- **必须优先选用成熟的开源组件库和解决方案**
- **严禁重复造轮子**
- 只有在现有开源组件/方案**确实无法满足需求**时，才允许进行自定义开发
- 技术选型前必须调研社区主流方案（如 Element Plus、Ant Design Vue、Vuetify 等）
- 自定义组件开发必须记录造轮子的理由和无法使用开源方案的论证
